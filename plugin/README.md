# ERP Page Forge plugin

Complete TypeScript plugin and Python engine source is maintained one directory above.

Build from the source tree: `npm install --legacy-peer-deps && npm run build`. Package with `npm pack`. Requires Node.js 20+, Python 3.10+, and a compatible DSH host (>=0.2.2-rc.1 <1.0.0). Optional image/browser features require Pillow/Playwright and a browser installed separately.

Public source profile does not bundle screenshots, captured customer material, binary dependencies, host SDK implementations, credentials, or model configuration. Model operations send selected content to the configured service.
