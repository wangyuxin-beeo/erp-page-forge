# 页面原型库 A1–A6 · 结构骨架与交互清单

> 生成页面前先在这里选原型。骨架 = 自上而下的区块顺序，**顺序不可调换**（ERP 用户靠肌肉记忆操作）。

---

## A1 · 管理列表页（最高频，占 ERP 后台 60%）

```
┌────────┬──────────────────────────────────────────────────────┐
│        │ 顶栏：采购管理 / 订单管理 / 销售订单        [搜索][头像]│
│ 侧边栏 ├──────────────────────────────────────────────────────┤
│ 216px  │ 页面头：销售订单管理            [导出][+ 新建订单]    │
│ 深色   │ 说明：共 12,486 条 · 数据截止 2026-09-17 09:30        │
│        ├──────────────────────────────────────────────────────┤
│        │ 查询区：订单号 | 客户 | 订单日期(起-止) | 状态 | 业务员 │
│        │        [查询][重置][展开更多]                        │
│        ├──────────────────────────────────────────────────────┤
│        │ 工具条：已选 2 项 [批量审核][批量导出]    表头设置 ⚙  │
│        ├──────────────────────────────────────────────────────┤
│        │ 数据表格（表头可排序 + 首列编码名称两行 + 状态胶囊）  │
│        │ ... 12 行 ...                                        │
│        │ 汇总行（可选）                                       │
│        ├──────────────────────────────────────────────────────┤
│        │ 分页：共 1,248 条  [10/页]  1 2 3 ... 125  跳至 [ ]  │
└────────┴──────────────────────────────────────────────────────┘
```

**必备要素**：查询区 ≥ 4 个条件、表头排序、行内操作 ≥ 3 个、批量选择、分页器、空状态
**交互清单**
1. 查询/重置：重置后所有条件清空并恢复全量
2. 表格排序：点击表头在 升序 → 降序 → 无 之间循环，表头显示 ▲▼
3. 全选 / 半选（indeterminate）复选框
4. 勾选后工具条显示"已选 N 项"并启用批量按钮
5. 行点击"详情" → 右侧抽屉展示完整字段（抽屉内为 A3 的简化版）
6. 分页切换后滚动回表格顶部，并显示当前页范围"第 1-10 条"
7. 筛选无结果 → 表格区显示空状态（图形占位 + "没有符合条件的数据" + "清空筛选条件"按钮）

**列配置建议**：复选框 / 编码+名称 / 关键业务字段 ×2-3 / 金额 / 状态 / 时间 / 负责人 / 操作 = 8–10 列

## A2 · 单据表单页（新建/编辑）

```
页面头：新建采购申请单                     [取消][暂存草稿][提交审批]
防错提示条：提交后单据进入审批流，审批期间不可编辑（浅主色底信息条）
┌ 卡片：单据信息 ───────────────────────────────────────────┐
│ 申请部门* | 申请人 | 申请日期* | 需求到货日期* | 采购类型*  │
└───────────────────────────────────────────────────────────┘
┌ 卡片：明细信息 ────────────────────────────── [导入][+ 添加行]┐
│ 行号 | 物料编码+名称 | 规格 | 需求数量 | 单位 | 单价 | 金额 | 需求日期 | 用途 | 删除 │
│ 1    | MAT-2026-0012 …                                        │
│ 合计行：                                  合计数量 6  合计金额 ¥12,860.00
└───────────────────────────────────────────────────────────┘
┌ 卡片：附件与说明 ─────────────────────────────────────────┐
│ 附件上传区（虚线框）+ 备注文本域                            │
└───────────────────────────────────────────────────────────┘
底部吸附动作条：[取消]  [暂存]  [提交审批]（右侧，带金额回显）
```

**必备要素**：必填星号、字段分组卡片、明细行可增删、自动合计、底部吸附动作条、校验提示
**交互清单**
1. 必填校验：空值提交时输入框描边变红 + 下方红字"请填写客户名称"，并滚动定位到第一个错误项
2. 明细行：数量 × 单价 自动算金额；增删行后合计实时更新（**先改数、再看合计，是评审必验点**）
3. 至少一行明细才能提交；数量必须 > 0，否则行内红字
4. 暂存 vs 提交：暂存只校验必填、不进入审批；提交校验全部
5. 底部动作条 `position:sticky; bottom:0`，长表单滚动时始终可见
6. 顶部信息条说明单据流转规则，减少误操作

## A3 · 主数据详情页

```
页面头：[← 返回]  物料：交流伺服电机 ASD-B2      [编辑][变更][停用]
头部摘要条：编码 MAT-2026-0012 · 类型 原材料 · 单位 台 · 状态 ●启用 · 版本 V1.2
┌ Tabs：基本信息 | 库存分布 | 关联单据 | 变更记录 ──────────────┐
│ 信息分组：基础属性（2 列 label-value）/ 库存与成本 / 审计信息  │
│ 每个分组标题 12px 大写 + 底部分割线                            │
└───────────────────────────────────────────────────────────────┘
右侧（可选）：关键指标小卡（库存数量、安全库存、标准成本、库龄）
```

**交互清单**
1. Tab 切换不刷新页面（纯 JS 显隐），当前项有 2px 主色下划线
2. 变更记录用**时间线**：版本号 + 变更人 + 时间 + 变更字段 diff（`标准成本 ￥1,180.00 → ￥1,240.00`，旧值灰删除线、新值主色）
3. 关联单据 Tab 是一个精简表（单据号 / 类型 / 日期 / 数量 / 状态），可点击跳转（Demo 中为占位）
4. 停用/变更等破坏性操作需二次确认弹窗
5. 头部摘要必须有状态标签，且状态改变时按钮组跟着变（启用态显示"停用"，停用态显示"启用"）

## A4 · 运营看板页

```
页面头：库存健康度看板     时间范围 [本月 ▼]  [刷新]  [导出快照]
KPI 行：4 张卡（含 数值 + 环比 + 微型趋势 + 语义色条）
  ┌ 库存总额 ¥8,642万 (+3.2%) ┐┌ 周转天数 62天 ↓4天 ┐
  ┌ 低于安全库存 17 项 ▲5 ┐   ┌ 呆滞库存占比 4.8% (-0.6pt)┐
中区（2 列网格）：
  ┌ 周转天数趋势（SVG 折线 + 目标线）——— 12 个月 ┐┌ 库存结构（横向条形：原材料/半成品/成品）┐
下区：
  ┌ 预警清单（表格：物料 / 仓库 / 当前库存 / 安全库存 / 缺口 / 状态 / 操作）┐
  ┌ 呆滞 TOP5 排行（条形 + 金额 + 库龄）┐
```

**交互清单**
1. KPI 卡内含：标题（12px 灰）+ 主数值（26px 粗）+ 环比（带 ▲▼ 与语义色）+ 底部 2px 语义色条
2. 图表时间范围切换（本月/本季/本年）→ 数值与图形随之变化（Demo 用 2-3 组预设数据切换即可）
3. 预警清单默认按"缺口"降序，须有 1-2 条危险色行，可点"去补货"跳转（占位）
4. 所有图表标注单位与口径说明（"周转天数=平均库存/日均出库成本"）
5. 缺数据时给"暂无数据"占位，不留空白框

## A5 · 审批工作台（三栏）

```
┌ 左栏 300px：待办(12) / 已办 / 我发起 ─┬ 中栏 弹性：单据详情 ────┬ 右栏 320px：审批轨迹 ──┐
│ 筛选：单据类型 紧急程度             │ 单据头部：单号 + 状态  │ ● 提交 张明 09-15 14:20 │
│ ┌ 任务卡（选中高亮左主色条）      │ 关键信息 2 列          │ │ 意见：…               │
│ │ 采购申请 PR-2026-09-0173       │ 明细表                 │ ● 部门经理 李静 09-15   │
│ │ 王磊 · 09-15 · 剩 6h（红）     │ 附件                   │ ○ 财务审核（当前节点）   │
│ │ ¥12,860 · 紧急                 │                        │ ○ 总经理审批           │
│ └                                │                        │                        │
│                                    │ 底部：[驳回][转办][同意]│                        │
└────────────────────────────────────┴────────────────────────┴────────────────────────┘
```

**交互清单**
1. 点击左侧任务卡 → 中栏与右栏内容随之切换（数据驱动，用一组 JS 对象渲染）
2. 紧急任务卡左侧 3px 危险色竖条 + 剩余时限红字；剩余时限按剩余小时数分色（>24h 灰、12-24h 橙、<12h 红）
3. 审批动作：同意 → 当前节点变已完成、下一节点变为当前（时间线立刻前进）；驳回 → 弹出意见输入框（必填）
4. 同意/驳回必须二次确认或填写意见，避免误操作
5. 待办计数在左栏标题上实时减少（点完一条从 12 → 11），这个细节最能体现"闭环"

## A6 · 台账 / 对账页

```
页面头：客户对账单                     [切换客户 ▼] [导出 Excel][打印]
条件条：客户 华东精密制造（示例） · 对账期间 2026-08-01 ~ 2026-08-31 · 账期 月结30
┌ 顶部资金摘要 4 格：期初余额 / 本期应收 / 本期已收 / 期末余额 ┐
┌ 明细台账（日期 | 单号 | 摘要 | 应收 | 已收 | 余额[累计] | 状态）│
│ ... 14 行 ...                                                  │
│ 汇总行：合计  应收 ¥1,286,400.00  已收 ¥1,024,000.00           │
└────────────────────────────────────────────────────────────────┘
底部：差异说明 + [确认对账] 差异金额 ¥0.00
```

**交互清单**
1. 余额列是**累计余额**（逐行累加），不是区间值；行内数字右对齐、等宽字体
2. 汇总行必须在滚动区域外固定（`tfoot` 粘底或独立汇总条），不受"显示多少行"影响
3. 打印样式：隐藏侧边栏与操作按钮（`@media print`），保留表头与汇总行，A4 竖版不溢出
4. 期间切换后摘要与明细同步刷新
5. 有差异时：差异金额标红 + 底部提示"存在 ¥2,400.00 差异，需人工复核"（对应安全红线里的人工复核）
