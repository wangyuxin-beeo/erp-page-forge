# 设计令牌与组件样式规则

> 本文件是 `SKILL.md` 第 6 节的展开版。生成页面时**只允许**使用下表中的值，出现表外色值即为不合格。

**语义色使用规则（不可混用）**

| 状态 | 用色 | 示例 |
|---|---|---|
| 完成/生效/正常 | `--ok` | 已生效、审核通过、库存充足 |
| 进行中/草稿/变更 | `--brand` / `--purple` | 已提交、变更中、执行中 |
| 待处理/临期 | `--warn` | 待审核、7 天内到期、低于安全库存 |
| 异常/拒绝/超期 | `--danger` | 已驳回、已作废、超期未交 |
| 中性/关闭 | `--text-3` 灰 | 已关闭、已归档 |

### 1.1 跨栈落地：目标项目已有令牌时怎么办

上表是**默认令牌**。当目标项目**已经有一套自己的设计令牌**时（探测方法见 `stack-adaptation.md` 第 1 节），
**整表服从目标项目**，而不是套用上表的值：

| 情形 | 做法 |
|---|---|
| 项目令牌能一一对应上表语义 | 建映射表，**整表替换**；产物里零上表原色值残留 |
| 项目令牌缺少某个语义档（如"信息紫"） | 取项目色系中最接近的档位；确无可用档位时才推导新值，且必须与项目色系同源、并在代码注释里写明依据 |
| 项目完全没有令牌体系 | 落上表默认值，并按第 4.x 节的形式落成 `:root` 变量 |

**为什么**：令牌是项目的品牌资产。新页面套用外来主色，会与项目其它页面明显割裂，评审时会被打回。
"禁止自写色值"这条纪律在跨栈场景下应理解为：**色值只能来自当前项目认可的令牌来源**。

**落地载体随项目的样式方案决定**：

| 项目样式方案 | 令牌落地方式 |
|---|---|
| 全局 CSS / CSS Modules | `:root` 下的 CSS 变量。**注意：CSS Modules 只隔离类名，`var()` 是运行时查找，照常全局有效**（前提是令牌文件已在入口全局引入） |
| SCSS / Less | `$var` 变量，必要时同时输出 `:root` 变量供运行时使用 |
| CSS-in-JS | 主题对象（`ThemeProvider` 的 theme 常量） |
| Tailwind | `theme.extend.colors` |
| 组件库（Element Plus / Ant Design 等） | 优先映射到组件库的主题变量，避免与库内既有组件风格打架 |

**字号与间距**通常不与项目冲突：项目未定义字号令牌时，直接沿用第 3 节的数值即可（"禁自写色值"约束的是色值）。

      浮层（抽屉/弹窗） 0 24px 48px rgba(16,24,40,.18)

## 4. 组件样式规则

### 4.1 侧边栏导航
- 分组标题：12px、`--text-3` 系（深底上用 `#5D6B85`）、letter-spacing 1px
- 菜单项：高 36px、圆角 8px、左内边距 10px、图标 16×16 圆角 5px
- 选中：底色 `--side-on` + 文字纯白 + `box-shadow: inset 2px 0 0 var(--brand)`
- 底部固定"当前用户"区，含姓名 + 角色 + 头像字块

### 4.2 顶栏
左：面包屑 `模块 / 菜单 / 当前页`（当前页加粗为 `--text`，其余 `--text-3`）
右：全局搜索框（可选）+ 通知圆点 + 用户头像块

### 4.3 页面头部（Page Head）
标题 20px/600 + 一行说明（`--text-3`，含"数据截止 xx"或规则说明）+ 右侧主次按钮组

### 4.4 查询区（Filter Bar）
- 白卡，内边距 16px，栅格 `grid-template-columns: repeat(auto-fill,minmax(200px,1fr))`
- 每格：label 12px `--text-2`（上方）+ 输入框高 34px
- 末尾一排操作按钮：`查询`（主）+ `重置`（次）+ 可选 `展开更多筛选`
- 输入框 focus：`border-color: var(--brand); box-shadow: 0 0 0 3px rgba(43,92,255,.12)`

### 4.5 数据表格
- 表头：底色 `#FAFBFD`、12.5px/500、`--text-2`、`border-bottom: 1px solid var(--line)`
- 行高 44px，hover 底色 `#FAFBFF`，选中行底色 `var(--brand-weak)`
- 对齐：**文字左对齐 / 金额数量右对齐 / 状态与日期居中 / 操作列右对齐或居中固定**
- 首列常为"编码 + 名称"两行式（编码 13px 主色可点，名称 12px `--text-3`）
- 行内操作：文字按钮，主色，多个之间用 `·` 或 12px 间距
- 排序表头带 ▲▼ 指示，可点击列 hover 显示手型
- 底部汇总行（A6 台账页必备）：底色 `#FAFBFD`、加粗、右对齐合计
- **数字列一律不折行**：`.num{font-variant-numeric:tabular-nums}` 之外必须再加
  `td.num{white-space:nowrap}`。否则列宽不足时 `2026-09-17` 会被折成两行，
  `¥1,286,400.00` 会被拆开 —— 这是最常见也最难自查的视觉缺陷。
- **表格容器必须能横向滚动**：`table` 包一层 `.tbl-wrap{overflow:auto}`，
  并给 `table{min-width:…}`。窄容器里让表格自己滚动，而不是挤压列宽或撑破页面。

### 4.5.1 栅格容错（避免整页横向溢出）

`1fr` 的隐式最小宽度是 `min-content`。当栅格单元里放的是**表头 `nowrap` 的表格**
或**长编码**时，`min-content` 会远大于可用宽度，于是整页被撑出横向滚动条，
违反"1280px 不横向滚动"的验收标准。

凡是栅格单元里可能装表格、长编码、长 URL 的，**固定列写死 px，弹性列一律写 `minmax(0,1fr)`**：

```css
/* 错：中间列会被表格顶开 */
.wrap{grid-template-columns:340px 1fr}

/* 对：中间列可以收缩到 0，内容交给内部滚动容器 */
.wrap{grid-template-columns:290px minmax(0,1fr)}
.detail-b>*{min-width:0}   /* 栅格子项同样要允许收缩 */
```

多栏工作台（A5）的固定栏位建议值：任务列表 290px、审批轨迹 264px；
可用宽度不足时用媒体查询把 4 列键值对降为 2 列，**不要靠缩小字号硬塞**。

### 4.6 状态标签（胶囊）
```
padding 2px 9px; font-size 12px; border-radius 999px; border 1px solid 同色系浅描边
成功：色 --ok   底 --ok-weak
警告：色 --warn  底 --warn-weak
危险：色 --danger 底 --danger-weak
进行：色 --brand 底 --brand-weak
信息：色 --purple 底 --purple-weak
中性：色 --text-2 底 #F1F3F7
```
**禁止**用彩色纯文字代替标签；**禁止**在同一个页面用同一颜色表达两种不同语义。

### 4.7 按钮
| 类型 | 样式 |
|---|---|
| 主按钮 | 底 `--brand`、白字、高 34px、圆角 6px、hover `--brand-strong` |
| 次按钮 | 白底、描边 `--line-strong`、字 `--text` |
| 文字按钮 | 无色无框，字 `--brand`，hover 加浅底 |
| 危险按钮 | 描边或文字用 `--danger`（作废/删除） |
| 禁用 | `opacity:.5; cursor:not-allowed`，且必须解释原因（如"请先选择数据"） |

### 4.8 抽屉 / 弹窗
- 详情抽屉：右侧 `width 520–640px`、白底、头部标题 + 关闭 ×、内容分区、底部动作条
- 遮罩 `rgba(16,24,40,.45)`，抽屉阴影用浮层阴影
- 支持 点击遮罩 / 右上角 × / Esc 三种关闭方式

### 4.9 Tabs / 时间线 / 进度
- Tabs：底部 2px 主色下划线指示当前项，未选中 `--text-2`
- 时间线（审批轨迹 / 变更记录）：左侧 2px 竖线 + 圆点，已完成圆点为主色实心，待处理为空心中性；每条含 动作 + 操作人 + 时间 + 意见
- 进度条：高 6px、圆角 999px、轨道 `--line`、填充按语义色

### 4.10 图表（手绘 SVG）
- 折线/柱状：主序列 `--brand`，对比序列 `--text-3`；网格线 `--line`（虚线）
- 柱状图柱宽 12–18px、圆角 3px 上沿
- 预警数据点用 `--danger`，达标数据用 `--ok`
- 必须标注单位（`单位：台 / 万元`）与时间范围

## 5. 视觉验收（截图即可判断）
1. 侧边栏深、内容区浅，明暗对比明确
2. 每屏最多 1 个主色按钮（其余为次/文字按钮）
3. 无彩色纯文字当状态用
4. 数字右对齐且等宽
5. 页面任意位置放大 200% 看：所有色值都来自令牌表
