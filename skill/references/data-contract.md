# Mock 数据契约

> 页面"像不像真的"取决于数据，不取决于配色。本文件规定数据怎么造。

## 1. 脱敏红线（硬性）

| 禁止 | 替代 |
|---|---|
| 真实客户 / 供应商名称 | `华东精密制造有限公司（示例）`、`苏州联动电子（示例）` |
| 真实人名 | 张明、李静、王磊、陈曦、赵敏、周昊（通用名，不叠用同一人身份） |
| 真实手机号 / 身份证 / 银行账号 | `138****6214`、`3201**********0011`、`6222 **** **** 8888` |
| 真实地址（含门牌） | `江苏省苏州市工业园区星湖街 000 号` |
| 未脱敏生产数据 | 数量与金额按业务量级重新构造，禁止复制真实数值 |
| 真实公司系统截图 / Logo | 使用自绘图形与文字标识 |

**统一免责标注**：页面页脚 `本页数据为演示用虚构数据，非真实业务数据`。演示视频与介绍页同样要标注。

## 2. 数量与分布要求

| 页面类型 | 最少行数 | 附加要求 |
|---|---|---|
| 列表页 A1 | 12 行 | 状态至少 4 种、含 1 条异常行、金额覆盖 4 位数到 7 位数 |
| 表单页 A2 | 4–6 明细行 | 合计 = 明细之和（必须真的算对） |
| 详情页 A3 | 关联单据 6 行 / 变更记录 5 条 | 变更记录含 1 条"价格上调"和 1 条"规格修订" |
| 看板页 A4 | KPI 4 个 / 趋势 12 点 / 预警 6 行 | 至少 1 个 KPI 是"变差"（红/橙），1 个是"变好" |
| 审批台 A5 | 待办 6 条 / 已办 4 条 | 至少 1 条剩余时限 <12h（红），1 条已超期 |
| 台账页 A6 | 14 行 | 逐行累计余额自洽、汇总行 = 明细求和 |

## 3. 格式规范

```
金额      ¥1,234,567.89（¥ 符号 + 千分位 + 两位小数）
大额汇总  可用 ¥8,642 万（KPI 卡内），但明细必须精确到分
数量      整数不带小数，物料按单位显示（120 台 / 2,400 kg），保留最多 3 位小数
百分比    3.2% / -0.6pt / 98.4%（涨跌点用 pt，比率用 %）
日期      2026-09-17   时间 2026-09-17 14:20
日期区间  2026-08-01 ~ 2026-08-31
编码      SO-20260917-0081 / PR-2026-09-0173 / MAT-2026-0012 / CUS-2026-0007
库龄天数  62 天（>180 天视为呆滞）
```
数字列一律 `font-variant-numeric: tabular-nums`，避免翻页时列宽跳动。

## 4. 自洽性检查（生成后必须自己算一遍）

1. **合计**：明细行金额之和 = 合计金额（在页面里逐行加一遍）
2. **余额列**：`上一行余额 + 本行应收 - 本行已收 = 本行余额`
3. **进度类**：已完工数量 ÷ 计划数量 = 进度百分比（误差 ≤1%）
4. **额度类**：已用额度 + 可用额度 = 信用额度
5. **库存状态**：当前库存 < 安全库存 → 状态必须是"预警/低于安全库存"，不能显示"充足"
6. **按钮可见性**：数据状态与操作按钮一致（已生效的单据不出现"编辑"）
7. **计数与列表一致**：标题"待办(12)"必须等于列表条数；"共 1,248 条"与分页总数一致

> 这 7 条是评审最可能抽查的地方，**任何一条不自洽都会让"AI 生成的页面"被认为不可信**。

## 5. 让页面"有故事"的三类数据

| 类型 | 作用 | 示例 |
|---|---|---|
| 异常 | 演示时能讲出问题 | 超信用额度、超期未交、低于安全库存、单据驳回 |
| 进行中 | 体现流程未闭环 | 待审核、生产中、部分发货、变更中 |
| 历史 | 体现数据资产厚度 | 去年同期的月度数据、已归档的 3 个版本 |

每页至少放 1 条异常数据，并在页面显眼处给出提醒（预警标签 / 顶部提示条 / 数值标红）。

## 6. 数据在页面中的组织方式（Demo 实现约定）

```js
// 单文件 Demo：数据放顶部常量，渲染函数统一读它，禁止把数据硬编码进 HTML 字符串
const ROWS = [
  { code:'SO-20260917-0081', customer:'华东精密制造有限公司（示例）', amount:128600.00, status:'已确认', due:'2026-09-30' },
  // ...
];
```

这样做的两个好处：① 改数据即改全页，不会遗漏；② 便于后续把 `ROWS` 换成真实接口返回值（只需替换数据源，渲染层不动）——这也是给评审演示"可接入真实系统"的关键。
