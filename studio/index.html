      使用说明 · 页面生成与原型还原
      
  
      
    
      按任务选择顶部的「模板库」「设计台」或「参考网页」。采集和生成结果保存在当前工作区，可在「产物与日志」中查看和下载。
      

    
      1模板库：快速生成 ERP 页面
      
    
      • 点击模板卡片的「预览」查看样式，点击「用它生成」填入示例指令。
        • 
      
      • 在输入框描述页面名称、字段和操作需求，选择主题；「解析」用于先检查指令识别结果，「生成代码」用于生成页面。
        • 
      
      • 模板类型包括管理列表、单据表单、主数据详情、看板、审批工作台、台账与对账。
        • 
      
      • 生成后查看页面、源码和验收结果；需要复用的页面可按结果区提供的入口保存为模板。
      

    
      2设计台：从截图或 Axure 开始
      
    
      • 点击「上传设计图」选择 PNG、JPG 或 WebP 图片，也可将图片拖入画布；公开源码版请上传自己的图片。
        • 
      
      • 点击「AI 识别」提取页面结构，核对识别出的文字、字段与按钮；不确定项应先修正再生成。
        • 
      
      • 需要手动调整时，使用「自动拆层」、框选和图层列表；选中图层后设置语义与名称。「按图层生成草稿」将标注整理成结构草稿。
        • 
      
      • 常用快捷键：V 选择/拖动，M 框选，I 取色，S 细分图层，方向键微移，Delete 移除。Ctrl / Shift 点击可多选。
        • 
      
      • Axure 导出文件夹请点击「导入 Axure」，填写本机导出目录、选择页面与主题，再点「读取并生成」。只有网址时请使用「参考网页」。
        • 
      
      • 点击「生成页面」，查看结果；「回到画布」可继续调整。AI 识别失败时可点击「自检」查看可读的错误提示。
      

    
      3参考网页：读取本机或内网原型
      
    
      1. 选择访问方式：公开网站选「公开网页」；本机浏览器原型或内网系统选「本机 / 授权内网原型」。
        2. 
      
      2. 输入带有 http:// 或 https:// 的完整地址，设置视口和最多采集页数。电脑须能访问该原型。
        3. 
      
      3. 需要登录时勾选「手动登录后采集」。在弹出的独立浏览器完成登录，再点击「登录完成，开始采集」。
        4. 
      
      4. 希望复用现有项目的主题和组件时，填写「当前项目目录」：选择本机前端项目根目录。留空可继续静态还原。
        5. 
      
      5. 点击「采集网页」，查看截图、主题来源、页面数及交互清单。可分别「导出页面数据」「导出页面主题」「导出原型与交互数据」或「下载完整包」。
        6. 
      
      6. 选择生成方式并补充要求：静态方式生成 HTML/CSS；「按项目主题生成代码包」根据关联项目的框架、主题和组件依赖生成新增文件建议。
        7. 
      
      7. 点击 AI 生成按钮，等待结果。静态方式可查看页面预览；项目代码方式显示交付说明，下载代码包后需在目标项目中构建、运行和验证。
      
    
      原型交互清单记录可读取的跳转、Tab、弹窗等声明；「待确认」表示尚未实际验证。保存、提交、删除、审批等真实业务动作不会自动执行。
      

    
      4工作区、结果与下载
      
    
      • 顶部工作区下拉框切换当前任务分组；「工作区」可新建、重命名或删除分组。删除前请确认提示，相关产物可能一并移除。
        • 
      
      • 「产物与日志」可按工作区、结果和名称筛选，打开历史页面、查看报告、下载单个文件或压缩包。
        • 
      
      • 「生成成功」表示文件已生成，不等于视觉、交互和项目编译均通过。先检查验收报告，再对照原型测试。
        • 
      
      • 项目代码包不会直接覆盖原项目；先审阅主题引用、路由接入和待补接口，再合入项目。
      

    
      5AI 与对话操作
      
    
      通过 DSH 插件进入时，AI 功能自动使用宿主选定的模型，无需在本页重复填写密钥；截图和原型还原需要模型支持图片。切换模型后如仍显示旧状态，可重新加载工作台或让 AI 重新打开 Studio。
      
    
      也可以直接在 DSH 对话中描述任务，例如：「使用页面生成插件，读取我提供的内网原型，关联当前前端项目，按项目主题生成代码包，并列出待确认交互。」AI 会调用插件工具并返回产物。
      
    
      采集在本机进行。点击 AI 识别或生成时，参考页面和必要的项目主题内容会交给当前模型处理；内部资料请选择组织允许使用的模型。无法连接时先确认原型可访问、模型可用，再根据界面提示重试。
